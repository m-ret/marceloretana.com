## La velocidad es la función principal

Cuando digo "rápido," no me refiero solo a entrega rápida (aunque eso también). Me refiero a sitios web rápidos.

Google mide la velocidad de tu sitio web con Core Web Vitals. Los sitios que cargan lento son penalizados en los rankings de búsqueda. La mayoría de sitios de pequeñas empresas sacan malas puntuaciones porque están construidos sobre plataformas infladas con docenas de plugins.

Construyo con **Next.js** — el mismo framework que usan Nike, Netflix y Notion. Tu sitio web de pequeña empresa corre sobre tecnología de nivel empresarial:

- **Tiempos de carga menores a un segundo** — Las páginas cargan antes de que tu visitante termine de parpadear
- **Renderizado del lado del servidor** — El contenido está listo cuando Google lo rastrea
- **Optimización automática de imágenes** — Las fotos cargan al tamaño correcto para cada dispositivo
- **Despliegue en el edge** — Tu sitio carga rápido desde cualquier parte del mundo

¿Por qué importa esto para una pequeña empresa? Porque el 53% de los visitantes móviles abandonan un sitio que tarda más de 3 segundos en cargar. Cada segundo lento te cuesta clientes.

## El SEO está integrado, no pegado encima

La mayoría de agencias web construyen tu sitio primero, y después "agregan SEO" como algo secundario. Tal vez instalan un plugin y listo.

Eso está al revés. En GEXP, el SEO es parte de la arquitectura:

### SEO técnico desde la primera línea

```
✓ Estructura HTML semántica (jerarquía h1, h2, h3)
✓ Meta tags generados dinámicamente para cada página
✓ Datos estructurados (JSON-LD) — le dice a Google exactamente qué hace tu negocio
✓ Sitemap XML — generado y enviado automáticamente
✓ URLs canónicas — sin problemas de contenido duplicado
✓ Diseño responsive mobile-first
✓ Core Web Vitals optimizados
```

### SEO local integrado en la base

Para negocios locales, agrego:

- **Schema de LocalBusiness** — Google entiende tu ubicación, horarios, servicios
- **Integración con Google Business Profile** — Tu sitio web y tu ficha de Maps trabajan juntos
- **Contenido específico por ubicación** — Páginas optimizadas para "[servicio] en [tu ciudad]"
- **Consistencia NAP** — Nombre, Dirección, Teléfono idénticos en todas partes

### Contenido que rankea

Ayudo a estructurar tu contenido para que responda las preguntas que tus clientes realmente buscan. No keyword stuffing — contenido genuino y útil que Google premia.
